## Why this exists

The blog is powered by local MDX files, so you can write essays, project notes, and image-rich posts without leaving the repository.

> A good portfolio can feel like an archive, a front page, and a studio wall at the same time.

Add a new `.mdx` file in `content/blog`, give it frontmatter, and it will appear in the blog index.
